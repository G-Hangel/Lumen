# Write Tests

When writing tests:

1. Identify inputs, outputs, and side effects.
2. Cover the happy path first.
3. Add edge cases: empty input, null, boundary values, errors.
4. Keep tests independent and deterministic.
5. Name tests clearly after the behavior being verified.
