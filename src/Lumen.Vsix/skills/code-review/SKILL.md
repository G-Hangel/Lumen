# Code Review

When reviewing code:

1. Check correctness: edge cases, null handling, off-by-one errors.
2. Check security: injection, path traversal, secret leakage.
3. Check maintainability: naming, duplication, test coverage.
4. Report findings grouped by severity: blocking, major, minor.
5. Suggest concrete fixes, not vague advice.
